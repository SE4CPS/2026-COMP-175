## Problem and fix

The initial service could not use SSH because Kali's global SSH configuration had a permission error when loaded by the user service. We set `ssh -F /dev/null` and explicitly supplied the required key, known-hosts file, host-key checking, and timeout options. The same request then returned the real Ubuntu result. During review, we also found that persona logins could run the app-management buttons. We added a separate operator login and server-side role checks, then retested both denied paths.
